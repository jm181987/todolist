# Todo List

Proyecto de lista de tareas para practicar organización y gestión de pendientes. Las funciones implementadas deben comprobarse en el código.

## Inicio rápido

Revisar archivos de entrada y dependencias antes de ejecutar.

```bash
git clone https://github.com/jm181987/todolist.git
cd todolist
```

## Documentación y mantenimiento

- Comprueba las dependencias, scripts y variables de entorno del repositorio antes de desplegar.
- No publiques tokens, contraseñas ni información privada.
- Registra los problemas con pasos para reproducirlos y resultados esperados.
